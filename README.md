
# Chess Positional Training

Chess Positional Training is a OAuth webapp that uses various Lichess APIs to let players practice from random positions and view live evaluations of each possible moves against the computer.

How it works:
- **Start where you want:** Focus on openings, middlegames, or endgames.

- **Play anyone:** Face a friend or the computer—each game begins from a random position, no memorization needed.

- **Pick your challenge:** Play from a winning, equal, or losing spot to build skills in all types of situations.

- **Toggle Evaluation Button:** See each move evaluations in real-time when playing against computer or maia bots (maia1, maia5, maia9) to improve your understanding.
